      Cast lists, filmographies and photos. Get a key under API settings on themoviedb.org. Either the API key or the read access token works.

      TVDB optional

      Photos of actors in character, for series. Get a key on thetvdb.com.

      Trakt optional

      Your watch history. Create an app at trakt.tv/oauth/applications with redirect URI urn:ietf:wg:oauth:2.0:oob, then paste its ID and secret here.
